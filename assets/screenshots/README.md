画廊卡片中的预览来自现有模板包的上游公开示例，具体来源、固定版本和校验值见 [模板注册表](../templates/registry.md) 及各模板 `manifest.json` 的 `preview_source`。这些公开预览保留上游署名，不代表当前用户的经历。

编辑器与事实页使用专门编写的虚构演示数据，包括“示例同学”“某某大学”“某科技团队”、`resume@example.com` 和占位电话。待确认、缺失阻塞与已省略的演示事实未写入简历正文。没有读取或截取用户的真实简历。

实拍验证覆盖：中英文分类切换、选模板事件、网页修改保存后重渲染、事实状态筛选，以及规范命名的一页 PDF 导出。素材、运行日志、会话令牌与构建中间产物不属于截图分发内容。

实拍时发现的 `{}GET` / HTTP 501 已在发布前修复：操作接口会先读取可选 JSON 请求体，避免影响同一 HTTP 连接上的后续轮询。已验证完成编辑、导出与重渲染接口后的连续事件请求，以及不带请求体的本地调用。
