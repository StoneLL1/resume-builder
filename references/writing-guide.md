# 简历撰写参考（resume-builder 配套）

> 蒸馏自 30 篇高赞简历方法论，作为 SKILL.md 第 6/7 步的**写作与自检**依据。所有示例为脱敏占位。
> 贯穿始终的原则：**匹配度 > 一切**。简历是"广告"不是"自传"，只放与目标岗位相关的内容；HR 只看约 30 秒，信息密度比信息量重要。

---

## 一、经历撰写公式

### 量化铁律
- 每条经历必须带数字：规模（用户数 / 金额 / 样本量）、比例（提升 X%）、排名（前 5%）、时长、产出（star / 篇数）。
- 没有精确数字 → 合理估算（"约 30%""近万条"）；实在没有 → 用规模 / 频次替代（"服务 3 个团队、每周 2 篇"）。
- 裸描述（"负责运营公众号"）≈ 没写。

### 三个公式（任选其一，都覆盖"做了什么 + 怎么做 + 结果"）

**STAR**

| 字母 | 含义 | 要写清 |
|---|---|---|
| **S** 情境 | 在什么背景 / 场景 | 为什么做这件事 |
| **T** 任务 | 你的任务是什么 | 你在情境里的具体职责 |
| **A** 动作 | 你做了什么 | 用动词 + 方法 / 路径 |
| **R** 结果 | 结果怎样 | 量化产出、是否达成目标 |

**场景化五步法**：场景 → 收集了什么信息 → 做出什么判断 → 做了什么动作调整 → 收获什么结果。

**三要素**：做了什么 / 怎么做的 / 达成什么（量化）。

### 改写示例

> ❌ 流水账：在 XX 公司市场部实习，负责公众号推文和活动执行。
>
> ✅ STAR 版：在 XX 公司市场部实习（S），独立负责小红书新品种草内容（T），每周策划 3 篇文案 + 剪 2 条短视频、优化标题关键词（A），4 周带动新品销量涨 15%、账号涨粉 500+（R）。

> ❌ 假大空：大大提升转化率。
>
> ✅ 量化：识别 3 类核心痛点，调整定价策略，转化率提升约 30%。

### 呈现技巧
- 关键词与数据 **加粗**。
- 动词开头：技术岗用 设计 / 开发 / 实现 / 优化 / 部署 / 重构；通用岗用 主导 / 统筹 / 搭建 / 优化 / 推动。
- 项目经历写"痛点"（难点 → 你怎么破局），凸显能力而非罗列职责。
- 每条不超 2 行，每段经历 2–4 条；项目"少而精"选 1–2 个。

## 二、结构与排序

基本顺序：基本信息 → 教育（倒序）→ 自我评价（可选）→ 工作 / 实习 → 项目 → 技能 / 证书。

- 优先级（应届）：**实习 > 项目 = 科研 > 校园经历**。
- 倒序：最新在前。
- **最相关的经历可提前**，不严格按时间。
- 自我评价：仅当有 JD 强相关卖点（教育高光 + 围绕 JD 的优势技能）才写；宽泛的"吃苦耐劳 / 有团队精神"不如不写，在经历中自然体现。
- 基本信息**只写四样**：姓名 / 电话 / 邮箱 / 求职岗位（+ 可选入职时间）。不放婚姻、住址、身份证。

## 三、分场景速查

### 技术岗
- 技术动词：设计 / 开发 / 实现 / 优化 / 部署 / 重构。
- 量化示例：接口响应时间降低 50%；缓存设计支撑每秒万级请求；准确率提升至 99%。
- 技能栈写岗位强相关项；**不熟的慎写**，面试一问就露馅。
- 加分项附链接：GitHub、技术博客、力扣。
- 自我评价、学生工作一般不写。

### 三无大学生（无实习 / 无项目 / 无经验）
- 校园经历是主战场：列出参与内容，归类，用小标题 + 数据。
- 用商赛、大创、毕设、校园项目、自媒体补足——"第一份经历是自己创造的"。
- 荣誉展开院校级，体现学习能力。

### 转行
- 找两个领域的**能力交集**（如实验数据分析 → 数据分析能力）。
- 用目标岗位的**行业术语**重新包装旧经历。
- 突出**可迁移技能**：项目管理、跨部门协作、逻辑思维。

### 运营岗
- 写得"对 / 垂直"比写得"多"重要。
- 工具要具体：Excel → 透视表 / VLOOKUP / 数据可视化；平台 → 推荐逻辑 / 违规率。
- 每条带活动规模、转化率、增长率。

### 外企 / 英文简历
- 四板块：Profile / Education（倒序，未获学位写 `Candidate for`）/ Experience（STAR + 强动词 Led/Managed/Improved + 量化）/ Additional Info。
- Times New Roman 或 Arial，标点全篇一致。
- 加分：跨文化交流、海外经历。

## 四、JD 关键词匹配（针对目标改简历）

1. 拆解 JD：提取核心能力要求与高频关键词。
2. 对照关键词：找出简历里的**匹配项**和**缺失项**。
3. 重组表述：用 JD 的措辞重写，让**关键词命中最大化**（同时只用 claim-map 中 ✅ 已确认的事实，不编造）。
4. **去"AI 味"**：最后用自己的话润色，删假大空，避免千篇一律的排比。

> 优化 ≠ 造假。只重新组织真实经历的表述，提高 ATS / HR 通过率。

---

## 五、排版红线

- **黑白 > 彩色**，最多一个强调色；全程灰黑零跳色。
- **上下结构 > 左右分栏**（左右挤压经历空间）。
- 最多**两种字体**；字号 标题 14 / 正文 10–12。
- **必须对齐**；合理留白，别密密麻麻。
- 大忌：花哨模板、满屏 icon / 装饰、超过两种字体、左右分栏、不对齐、用 Word 投递。
- 黄金法则：没有发光 / icon 满天飞，"很稳地坐那儿"反而最耐看、最显高级。
- ATS 场景优先单栏、无表格、无照片（billryan / luooofan 适配）。

---

## 六、投递规范

- **命名**：`姓名-目标岗位-电话.pdf`；实习 `姓名-学校-到岗时间-时长`；技术岗 `姓名-应聘岗位-联系方式`。别叫"我的简历.pdf"。
- **格式**：PDF，不用 Word（排版会乱）。
- **黄金时段**：周二~周四 9:30–11:30、14:00–16:00；避开周一（邮件积压）、周五 / 周末。
- **多份简历**：有几个方向就做几份针对性简历，通投是最蠢的做法。
- **打招呼**（前 20 字突出关键信息）：应届 →"XX 级应届生，毕业于 XX 大学 XX 专业，应聘 XX 岗位…"；职场人 →"X 年 XX 经验，负责过 XX 项目，带来 X 价值…"。

## 七、交付前检查清单（详版）

投递前逐条打勾，全绿再发：

- [ ] 一页纸，不超过两种字体 / 颜色
- [ ] 黑白配色、上下结构、对齐、留白合理
- [ ] 求职岗位明确（一个，不是"都可以"）
- [ ] 基本信息：姓名 + 电话 + 邮箱 +（求职岗位）
- [ ] 每段经历都有量化数据，关键词已加粗
- [ ] 经历用 STAR / 场景化公式描述
- [ ] 与目标无关的经历已删除或缩减
- [ ] 无错别字、无技术 / 专业名词拼写错误（通读 3 遍）
- [ ] 文件名规范：姓名-目标岗位-电话.pdf
- [ ] PDF 格式投递
- [ ] 有几个方向就做了几份不同简历
- [ ] 写上去的经历 / 技能面试都能讲清，数据经得起追问
