# 写作阶段（阶段 A）：对话收集与模板无关撰写

> 读取时机：skill 首次调用、或恢复 `session.json` 处于 `writing` 阶段的项目时。
> 本文件只负责**工作流、claim-map 协作和阅读路由**；写作方法论（怎么写好一条
> bullet、怎么拆 JD、各岗位结构）一律以同目录 `Resume-Writing-Guide-LLM.md`
> 为准，本文不重复。

## 0. 阅读路由（本阶段读什么）

| 时机 | 动作 |
|---|---|
| 开始信息整理、登记事实、提问 | 只用本文，不必读指南 |
| **动笔撰写 / 改写 / 审计 / 针对 JD 定制之前** | **完整读取** `Resume-Writing-Guide-LLM.md`（一次会话读一次即可，后续按需回查章节） |
| 素材与内容稿充分 | 转入阶段 B，读 `references/template-selection.md` |

阶段 A 全程：**不启动本地服务、不读渲染 / 模板 / 数据契约文档、不讨论排版与模板实现**。用户问模板效果时，回答"选定阶段会看到全部真实渲染的模板"即可。

## 1. 工作流

1. **建项目目录**：`<用途>/` 与 `<用途>/work/`（结构见 SKILL.md「项目归档」）。
2. **收集素材**：用户提供 PDF（用工具提取文本）、粘贴文字或口述。整理进
   `<用途>/work/信息整理.md`：按 身份 / 教育 / 经历 / 项目 / 技能 / 荣誉 分类，
   每条素材**注明来源**（原 PDF 第 N 页 / 用户口述 / 用户某次答复）。这份文件是
   素材库，宁多勿漏，取舍在后面做。
3. **确认目标**：明确「背景 + 目的」——求职（什么岗位，最好拿到 JD）/ 比赛
   （什么赛题方向）/ 升学（什么项目）。同时确认**语言模式**（中文 / 英文）与**页数预期**（默认 1 页，内容确实多再 2 页）。目标不清先问清再动笔。
4. **初始化 claim-map**：把已知事实按四态登记进 `work/claim-map.md`
   （格式与高危类目见 SKILL.md「事实与防幻觉」）。信息整理里的每条素材
   都应有对应 claim 行，或明确不打算用。
5. **完整读写作指南**（见 §0 路由）。
6. **信息筛选**：按目标挑相关项、舍弃无关项，给用户一张「保留 vs 舍弃」对照表
   并说明理由。高危项缺失的，在 claim-map 标 ⛔。
7. **分批缺口提问**（见 §3）。
8. **产出模板无关内容稿**（见 §4）。

## 2. claim-map 协作规则

| 情形 | 动作 |
|---|---|
| 用户确认了一条事实 | 对应行改 ✅ |
| 用户说"没有 / 跳过 / 不写" | 改 ➖ 已省略，**不再追问** |
| 发现高危项缺失 | 标 ⛔，进入动笔前必须解决 |
| 暂时拿不准、先不写入 | 标 ❓，攒一批再问 |
| 用户在网页编辑器里改了措辞 | **不**自动改状态；claim 仍以对话确认为准 |
| 导出 | claim 状态**不**阻止导出（网页也不拦） |

规则不变项：**撰写只能动用 ✅ 已确认事实**；高危项要么确认、要么经用户同意省略；不脑补、不擅自升级措辞。

## 3. 提问策略

- 分优先级（⭐⭐⭐ 阻塞项 / ⭐⭐ 含金量项 / 次要）**批量**提问，一次 3–6 个问题，不来回挤牙膏。
- 优先问能显著提升含金量的硬信息：绩效数字、对口项目、数理基础、技能深度。
- **引导给数字但不逼造数字**：用户说没有可信数字，就转而问真实的上线 / 采用 /
  验收 / 规模 / 交付物 / 外部认可（指南 §5.1）。**绝不建议用户"估一个"**。
- 用户每答一条，及时更新 claim-map 状态。

## 4. 内容稿要求（模板无关）

- **素材库完整，内容稿精选**：完整表达拟保留经历的关键证据，篇幅先不受模板限制；无关素材和重复表述不进入内容稿，阶段 C 再按实际版面精修。
- 板块结构与排序按指南 Step 5 决定（相关性优先于严格时间倒序）。
- 不写任何排版指令（字号 / 分栏 / 颜色 / 模板名），不猜测模板能力。
- bullet 写法、模块规范、分岗位结构**完全按指南**（§4–§8），本文不另设标准。
- 内容稿在对话中呈现给用户确认，不必落盘成独立文件；定稿素材就是
  `信息整理.md` + `claim-map.md` + 对话中的内容稿。

## 5. 定稿前自检

内容稿定稿时，结合指南 §14 检查岗位重点、个人贡献与表达，并对照 claim-map 确认所有事实均为 ✅，无编造或夸大。指南 §15 仅在需要评分诊断时参考，不要求每轮打分；后续排版改写按 rendering-stage.md §4 复核变化部分。

## 6. 进入阶段 B 的判据

见 SKILL.md「何时进入模板选择」。达成后：

1. 告知用户：素材已充分，即将打开模板画廊（中文与英文各 9 套真实模板，由用户亲自选）。
2. 读取 `references/template-selection.md` 继续执行。
